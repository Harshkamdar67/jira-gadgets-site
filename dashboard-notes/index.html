Dashboard Notes

Put formatted notes, checklists, tables, links and images on any Jira Cloud dashboard. Free.

Add it to a dashboard

  1. Open a dashboard and select Edit.
  2. Select Add gadget, search for Dashboard Notes, then select Add.
  3. The gadget opens its editor. Write your notes and select Save.

To change a note later, edit the dashboard, open the gadget's ⋯ menu and select Configure.

What you can put in a note

ContentHow
HeadingsToolbar H1–H3, or type #, ##, ### and a space
Bold, italic, underline, strikethrough, codeToolbar, or Ctrl/Cmd + B, I, U
Bullet, numbered and check listsToolbar, or type -, 1. or [ ] and a space
LinksToolbar link button, or paste a web address
ImagesToolbar image button, paste, or drag and drop. Large images are resized automatically.
Tables, quotes, dividersToolbar

Options

  • Accent: a coloured bar down the left edge, so important notes stand out.
  • Compact spacing: less padding, for small gadgets and wallboards.
  • Earlier versions: the last five saved versions. Restoring one keeps the current version in the list.

Good to know

  • The gadget follows Jira's light or dark theme automatically.
  • Links open in a new browser tab.
  • Each note can hold up to 20 images. Very long notes may need splitting across two gadgets.
  • Anyone who can edit the dashboard can change the note. Everyone who can see the dashboard can read it.

Your data

Notes and images are stored in Atlassian's app storage for your Jira site and never leave Atlassian. See the privacy policy.
